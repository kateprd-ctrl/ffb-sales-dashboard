# Сборка страниц

Страницы `index.html`, `daily.html` и `motivation.html` собирает скрипт из данных Google-таблицы «Отчет воронка ОП (с данными)» (аккаунт компании, spreadsheetId `12c4dKMcaPuvgCmp7KU-XGXDiCuthZwdNK1dlahTuZfE`) и шифрует паролем.

Старая таблица «Отчет воронка FFB» (`1erqgI8dXKMnWrraeHN2P-mi_EiO3yTkReGZ7QXI8UWU`) с 05.11.2026 не обновляется и переименована в «АРХИВ, не использовать». Её читать нельзя.

Как всё связано (время по Таллину, будни):
- около 9:43 и 19:25 скрипт Apps Script пишет данные из Bitrix24 в таблицу;
- в 9:58 и 19:58 задача по расписанию собирает страницы и пушит сюда;
- в 10:12 задача «План KPI» дописывает снимок в лист «План — история»;
- в 10:25 и 20:25 «сторож» сверяет дату последнего дня в `daily.html` с таблицей и сообщает о поломках.

При переносе таблицы или смене её ID нужно поменять ID во всех задачах по расписанию (сборка, План KPI, сторож) и в этом файле.

1. `python3 tools/ingest.py /tmp/ing <файлы с ответами Google Sheets>` — раскладывает данные.
2. `PAGE_PASSWORD=... python3 tools/build.py /tmp/ing/data.json /tmp/out` — собирает и шифрует.
3. Файлы из `/tmp/out` копируются в корень репозитория.

Пароль в репозитории не хранится. Данные в репозитории только в зашифрованном виде.

## Страница лидов выставки (whitelabelexpo.html)

Собирается отдельно от основных страниц: `WLE_PASSWORD=... python3 tools/wle_build.py LEADS.json LETTERS.json STAGES.json DAILY.json whitelabelexpo.html`.
Входные файлы это ответы Google Sheets get_values по листам таблицы «Whitelabelexpo — лиды выставки» (список листов и диапазонов в начале `wle_build.py`). Шаблон страницы: `wle_tpl.html`. Пароль в репозитории не хранится, данные только в зашифрованном виде.
